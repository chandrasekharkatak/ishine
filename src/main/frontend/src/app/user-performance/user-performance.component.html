APPRAISAL INSTRUCTIONS

Use these guidelines while evaluating employees. This includes rating ranges and how to enter scores (slider or stars).

Rating Criteria (0 to 5)

NI 0 - 1.5 Needs Improvement
M- 1.6 - 2.4 Meets Expectations (Lower Band)
M 2.5 - 3.4 Meets Expectations
M+ 3.5 - 4.4 Meets Expectations (Upper Band)
E 4.5 - 5 Exceeds Expectations

Rating Input Styles

Slider Use range slider from 0 to configured max for criteria-based scoring.
Rating Use star rating selection for direct score-based criteria.

Follow the approval sequence from manager to HOD to HR, including rejections and final completion.

Performance Flow (Step by Step)

1

Manager Review: Manager opens employee evaluation, gives ratings and remarks, then submits.

2

HOD Review: HOD verifies manager inputs, updates remarks/rating if needed, then accepts or rejects.

3

HR Review: HR reviews accepted/rejected records, can edit final remarks/rating, then accepts or rejects.

4

Rejected Cases: If rejected by HOD/HR, updated feedback and rating should be resubmitted in next action.

5

Completion: Review status is marked complete after required approvals are finalized.

Follow the above criteria and approval sequence for consistent and fair performance evaluation.
